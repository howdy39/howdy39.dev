title: "Building a Looker Studio dashboard that visualizes SaaS usage with the Admina API from GAS"
description: "I made SaaS usage visible in Looker Studio by calling Admina's API from GAS. GAS calls two Admina endpoints in sequence, writes the results to a spreadsheet, and Looker Studio visualizes them. You can search by email address to see which services a person uses, or filter by offboarding status to find accounts that were missed during deletion. The GAS is written in TypeScript with clasp, and a run takes about 30 seconds to 3 minutes."
