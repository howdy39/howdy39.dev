title: "Thinking about My Notion Way"
description: "Notion lets you build freely like Lego, which is exactly what makes it hard to use. So I wrote about how I use it. The key is databases: put pages in a database by default, start with a single database and split it when needed, drop the folder mindset, hide the sidebar and use search (cmd/ctrl + K). I give pages unique names, for example by combining a date with a recurring meeting name, and avoid changing the default settings as much as I can."
