このサイトは、Mintlify の AI ネイティブな機能で、AI にもそのまま読んでもらえるようにしています。人が読むページとは別に、AI 向けの入り口があります。日本語版と英語版の、どちらも使えます。

## 入り口の一覧

- **llms.txt**: [https://howdy39.dev/llms.txt](https://howdy39.dev/llms.txt)<br />サイト全体の目次です。どんなページがあるかを、AI が把握します。
- **llms-full.txt**: [https://howdy39.dev/llms-full.txt](https://howdy39.dev/llms-full.txt)<br />記事の紹介文を含む、全ページの内容をまとめたものです。
- **英語版の索引**: [https://howdy39.dev/_llms/en.md](https://howdy39.dev/_llms/en.md)<br />英語版のページの目次です。
- **ページの Markdown**: 各ページの URL の末尾に `.md` を付けます。<br />例: [https://howdy39.dev/ja.md](https://howdy39.dev/ja.md)
- **MCP サーバー**: `https://howdy39.dev/mcp`<br />AI ツールから、このサイトを検索して読みます。

## MCP サーバーにつなぐ

MCP サーバーにつなぐと、AI ツールがこのサイトを検索して、ページの内容を読んでくれます。「howdy39 が書いた Notion の記事を教えて」のように、AI に聞けます。

MCP サーバーの URL は `https://howdy39.dev/mcp` です。

### Claude（claude.ai）

1. [Connectors](https://claude.ai/settings/connectors) を開きます。
2. **Add custom connector** を押します。
3. 名前に `howdy39.dev`、URL に `https://howdy39.dev/mcp` を入れて、**Add** を押します。
4. 会話の入力欄の「＋」から、`howdy39.dev` を選びます。

### Claude Code

```bash
claude mcp add --transport http howdy39-dev https://howdy39.dev/mcp
```

### Cursor など

`mcp.json` に、次のように書きます。

```json
{
  "mcpServers": {
    "howdy39-dev": {
      "url": "https://howdy39.dev/mcp"
    }
  }
}
```

### できること

- `search_howdy39_dev`: サイトの内容を検索します。
- `query_docs_filesystem_howdy39_dev`: ページを、ファイルのように開いて読みます。

対象は、公開しているページの内容だけです。読み取り専用で、ページの誤りを報告するツールだけが、書き込みになります。
